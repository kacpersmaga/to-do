# 📋 To-Do Project

Welcome to the **To-Do Project**! This simple yet functional to-do list application was created as a learning project to practice JavaScript, front-end development, and project organization using modern tools and techniques.

## 🚀 Project Overview

The To-Do Project is a task management app that allows you to:

- **Create and delete projects**.
- **Add tasks with details** like priority, due date, and completion status.
- **Filter tasks** (e.g., all tasks, today's tasks, completed tasks).
- **Persist data** using **Local Storage**, so your tasks are saved even if you refresh the page.

## 🛠️ Key Learnings

This project helped me gain valuable experience in several areas:

### 1. **Webpack Configuration**
- I learned how to set up and use **Webpack** to bundle my JavaScript files.
- Configuring **loaders and plugins** helped me understand how to manage assets and improve project structure.

### 2. **File Organization**
- I practiced **grouping files** by functionality, making the project modular and easier to navigate.
- The project structure follows the **MVC pattern** (Model, View, Controller) for clear separation of concerns.

### 3. **Single Responsibility Principle**
- Each class was designed to have a single responsibility:
  - **ProjectRepository** manages data persistence.
  - **ProjectUI** handles the user interface.
  - **TaskUI** manages task-specific interactions.
- This approach made the codebase cleaner and easier to maintain.

### 4. **DOM Manipulation**
- I improved my skills in working with the **Document Object Model (DOM)** to dynamically update the UI based on user interactions.
- The project uses modern JavaScript features like **template literals** and **arrow functions** for efficient DOM manipulation.

### 5. **Local Storage**
- I learned to use **Local Storage** to store user data persistently.
- The application saves projects and tasks locally, making it functional without a back-end server.

## 💡 Areas for Improvement

While the core functionality is solid, the **front-end design** can be improved to provide a better user experience. Potential enhancements include:

- Adding a **responsive layout** for mobile devices.
- Improving the **styling** with a modern UI framework like **Tailwind CSS** or **Bootstrap**.
- Adding **animations** and better error handling for a smoother user experience.

## 📦 Installation & Usage

To run this project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/kacpersmaga/to-do.git
   cd todo-project
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Build the project**:
   ```bash
   npm run build
   ```

4. **Start the development server**:
   ```bash
   npm start
   ```

5. **Open the app in your browser**:
   ```
   http://localhost:8080
   ```
